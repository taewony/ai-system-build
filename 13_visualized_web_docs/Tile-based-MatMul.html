원리 설명: 공유 메모리란?

GPU에서 행렬 연산을 할 때 가장 큰 병목은 '계산 속도'가 아니라 '데이터를 가져오는 속도'입니다. GPU의 메인 메모리(VRAM, 글로벌 메모리)는 용량이 크지만 속도가 느립니다.

  • 일반 방식 (Naive): 결과 행렬의 각 칸을 계산할 때마다 VRAM에서 전체 행과 열을 계속 다시 읽어옵니다. 엄청난 트래픽 낭비가 발생합니다.
  • 타일링 방식 (Tiling): 행렬을 작은 블록(타일)으로 잘라, 칩 내부에 있는 아주 빠르고 작은 창고인 '공유 메모리(Shared Memory)'에 한 번만 가져다 놓습니다. 그리고 그 안에서 여러 번 재사용하여 계산을 끝냅니다. VRAM 접근 횟수가 기적적으로 줄어듭니다!

RTX 4060 예상 성능 계산

크기가 N=4096인 행렬 A와 B를 곱할 때 (4096 × 4096):

[타일링 미적용 시]
메모리 읽기 횟수: $2N^3$ = 약 137,438,953,472 회 (137 Billion)
결과: 대역폭(272GB/s) 한계에 부딪혀 연산기가 놀게 됨 (Memory Bound)
[32x32 타일링 적용 시]
메모리 읽기 횟수: $2N^3 / 32$ = 약 4,294,967,296 회 (4.2 Billion)
결과: VRAM 접근이 1/32로 감소하여 GPU의 15 TFLOPS 연산력을 100% 가동 가능.
