원리 설명: 타일(Tile)과 스레드 블록

GPU는 수많은 코어를 가지고 있습니다. 효율적인 분업을 위해 전체 행렬을 작은 타일(이 예제에서는 4x4) 단위로 쪼갭니다.

  • 2x2 타일 배치: 8x8 행렬을 계산하기 위해 총 4개의 타일 구역이 만들어집니다. (시각화의 굵은 선 참조)
  • 스레드 블록 (Thread Block): 각 결과 타일은 GPU 내부의 '스레드 블록'이라는 작업 반장에 할당됩니다. 즉, 4개의 블록 프로세서가 각자의 타일을 책임집니다.
  • 병렬 처리 (Parallelism): 블록 안에는 타일 크기(16칸)만큼의 일꾼(스레드)이 있습니다. 이들은 느린 VRAM에서 16개의 데이터를 한 번에 공유 메모리로 가져온 뒤, 공유 메모리 안에서 16칸의 계산을 동시에 수행합니다.

[일반 방식]
메모리 읽기: 칸마다 전체 행/열을 매번 VRAM에서 읽어 약 1,374억 회 발생. VRAM 대역폭 병목으로 GPU 연산기가 대기(Stall) 상태에 빠집니다.
[32x32 타일링 적용 시]
메모리 읽기: 각 스레드 블록(1024개 스레드)이 32x32 타일을 공유 메모리에 올려놓고 재사용하므로, VRAM 접근 횟수가 1/32인 약 42억 회로 급감합니다. 공유 메모리 덕분에 GPU의 15 TFLOPS 연산력을 100% 가동할 수 있습니다.
