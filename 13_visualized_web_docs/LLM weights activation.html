가중치 (Weights)

  • 모델이 학습한 '지식' 자체. (파라미터)
  • 추론(Inference) 중에는 값이 절대 변하지 않는 읽기 전용(Read-only) 데이터.
  • 마치 하드디스크에 설치된 프로그램(예: Ubuntu ISO 파일)과 같습니다.
  • VRAM 점유율: 모델 크기(7B, 70B 등)에 비례하여 항상 엄청난 고정 메모리를 차지합니다.

활성화 값 (Activations)

  • 입력 데이터가 각 레이어를 통과하며 계산되는 '중간 결과물'.
  • 토큰이 입력될 때마다 실시간으로 생성되고 변하는 동적(Dynamic) 데이터.
  • 마치 실행 중인 프로그램이 사용하는 RAM(작업 메모리)과 같습니다.
  • VRAM 점유율: 배치 크기(사용자 수)나 프롬프트 길이에 따라 동적으로 폭증합니다. (KV Cache가 바로 이 과거 활성화 값을 저장해 둔 것!)
