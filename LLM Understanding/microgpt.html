microGPT 코드 딥다이브

안드레이 카파시(Andrej Karpathy)의 최소 구현체 분석

PyTorch 코드로 이해하는 GPT 구조의 본질

1. 데이터 전처리와 토크나이저 (Tokenizer)

# 문자(Character) 단위의 아주 간단한 토크나이저 구축
chars = sorted(list(set(text)))
vocab_size = len(chars)

# 매핑 딕셔너리 생성 (문자 <-> 정수 인덱스)
stoi = { ch:i for i,ch in enumerate(chars) }
itos = { i:ch for i,ch in enumerate(chars) }

# 인코더와 디코더 함수
def encode(s):
    return [stoi[c] for c in s]

def decode(l):
    return ''.join([itos[i] for i in l])

# 예시
# encode("hi there") -> [46, 47, 1, 58, 46, 43, 56, 43]

Character-level Tokenizer

microGPT는 복잡한 BPE(Byte-Pair Encoding) 대신 문자 단위(Char-level)를 사용하여 복잡도를 최소화합니다.

  • set(text): 데이터셋에 존재하는 모든 고유 문자를 추출합니다.
  • stoi (String to Integer): 문자를 모델이 이해할 수 있는 정수(Index)로 변환합니다.
  • itos (Integer to String): 모델이 생성한 정수(Index)를 다시 사람이 읽을 수 있는 문자로 변환합니다.

2. CausalSelfAttention 클래스 (초기화)

class CausalSelfAttention(nn.Module):
    def __init__(self, config):
        super().__init__()
        assert config.n_embd % config.n_head == 0
        
        # Q, K, V를 위한 단일 Linear 레이어 (성능 최적화)
        self.c_attn = nn.Linear(
            config.n_embd, 3 * config.n_embd, bias=False
        )
        
        # Attention 결과를 다시 원래 차원으로 투영
        self.c_proj = nn.Linear(
            config.n_embd, config.n_embd, bias=False
        )
        
        self.n_head = config.n_head
        self.n_embd = config.n_embd

Q, K, V 벡터의 생성

Attention 연산을 위해서는 각 토큰마다 Query, Key, Value 3개의 벡터가 필요합니다.

  • self.c_attn: Q, K, V를 각각 따로 선언하지 않고, 한 번의 행렬 곱(3 * n_embd)으로 병렬 처리하여 속도를 높이는 것이 실무적인 최적화 기법입니다.
  • self.c_proj: 여러 Head에서 계산된 Attention 결과를 결합한 후, 다음 레이어로 넘기기 위해 차원을 다시 맞춰줍니다.

3. CausalSelfAttention 클래스 (Forward)

def forward(self, x):
    B, T, C = x.size() # Batch, Time, Channels
    
    # 1. Q, K, V 계산 및 분리
    qkv = self.c_attn(x)
    q, k, v = qkv.split(self.n_embd, dim=2)
    
    # 2. Multi-head를 위해 차원 재배열 (B, nh, T, hs)
    k = k.view(B, T, self.n_head, C // self.n_head).transpose(1, 2)
    q = q.view(B, T, self.n_head, C // self.n_head).transpose(1, 2)
    v = v.view(B, T, self.n_head, C // self.n_head).transpose(1, 2)
    
    # 3. Flash Attention 적용 (PyTorch 2.0+)
    y = F.scaled_dot_product_attention(
        q, k, v, is_causal=True
    )
    
    # 4. 차원 복구 및 Projection
    y = y.transpose(1, 2).contiguous().view(B, T, C)
    return self.c_proj(y)

Masked Attention 핵심

이 코드는 GPT가 '다음 단어 예측기'로 동작하게 만드는 핵심입니다.

  • split(): 아까 붙여서 계산했던 qkv를 다시 3조각으로 나눕니다.
  • is_causal=True: PyTorch 내장 함수를 사용하여 최적화된 연산을 수행합니다. 이 옵션이 과거의 토큰이 미래의 토큰을 보지 못하게(Masking) 막는 역할을 합니다. (생성 모델의 필수 조건)

4. MLP와 Block (Transformer 1계층)

class MLP(nn.Module):
    def __init__(self, config):
        super().__init__()
        self.c_fc   = nn.Linear(config.n_embd, 4 * config.n_embd)
        self.gelu   = nn.GELU()
        self.c_proj = nn.Linear(4 * config.n_embd, config.n_embd)

    def forward(self, x):
        return self.c_proj(self.gelu(self.c_fc(x)))

class Block(nn.Module):
    def __init__(self, config):
        super().__init__()
        self.ln_1 = nn.LayerNorm(config.n_embd)
        self.attn = CausalSelfAttention(config)
        self.ln_2 = nn.LayerNorm(config.n_embd)
        self.mlp = MLP(config)

    def forward(self, x):
        x = x + self.attn(self.ln_1(x))
        x = x + self.mlp(self.ln_2(x))
        return x

Residual & LayerNorm

하나의 Transformer Block은 Attention과 Feed-Forward Network(MLP)로 구성됩니다.

  • MLP: Attention으로 섞인 토큰 정보들에 대해 비선형적(GELU) 계산을 수행하여 모델의 표현력을 높입니다. (차원을 4배로 키웠다가 줄임)
  • x = x + ...: Residual Connection(잔차 연결)입니다. 깊은 신경망에서도 기울기(Gradient)가 소실되지 않고 잘 흐르도록 돕습니다.

5. GPT 모델 전체 조립

class GPT(nn.Module):
    def __init__(self, config):
        super().__init__()
        self.config = config

        self.transformer = nn.ModuleDict(dict(
            # 토큰 임베딩 (단어 사전 -> 벡터)
            wte = nn.Embedding(config.vocab_size, config.n_embd),
            # 위치 임베딩 (위치 순서 -> 벡터)
            wpe = nn.Embedding(config.block_size, config.n_embd),
            # Transformer Block들을 반복 생성
            h = nn.ModuleList([Block(config) for _ in range(config.n_layer)]),
            # 최종 LayerNorm
            ln_f = nn.LayerNorm(config.n_embd),
        ))
        
        # 최종 단어 예측을 위한 Linear Layer (Logits 출력)
        self.lm_head = nn.Linear(config.n_embd, config.vocab_size, bias=False)

아키텍처의 완성

앞서 만든 Block을 쌓아 완전한 GPT를 만듭니다.

  • wte (Word Token Embedding): 입력된 정수(토큰)를 의미를 담은 벡터로 변환.
  • wpe (Word Positional Embedding): "단어의 순서" 정보를 벡터로 변환. Attention은 순서를 모르기 때문에 필수적입니다.
  • lm_head: 최종 벡터를 다시 사전 크기(vocab_size)로 변환하여 어떤 단어가 올지 점수(Logits)를 냅니다.

6. 순전파(Forward)와 손실(Loss) 계산

def forward(self, idx, targets=None):
    B, T = idx.size()
    pos = torch.arange(0, T, dtype=torch.long, device=idx.device)
    
    # 토큰 벡터 + 위치 벡터
    tok_emb = self.transformer.wte(idx)
    pos_emb = self.transformer.wpe(pos)
    x = tok_emb + pos_emb
    
    # Block 통과
    for block in self.transformer.h:
        x = block(x)
    x = self.transformer.ln_f(x)
    logits = self.lm_head(x)
    
    loss = None
    if targets is not None:
        # 예측값(logits)과 실제 정답(targets) 사이의 오차 계산
        loss = F.cross_entropy(
            logits.view(-1, logits.size(-1)), 
            targets.view(-1)
        )
    return logits, loss

예측과 정답의 비교

데이터가 모델을 통과하여 학습되는 과정입니다.

  • tok_emb + pos_emb: 단어의 의미 정보와 위치 정보를 단순히 더해서 입력으로 사용합니다.
  • F.cross_entropy: 모델이 예측한 다음 단어의 확률 분포(logits)와 실제 다음 단어(targets)의 차이를 계산합니다. 이 loss를 최소화하는 것이 학습의 목표입니다.

7. 텍스트 생성 루프 (Generate)

# @torch.no_grad()를 통해 그래디언트 계산 비활성화 (추론 모드)
def generate(self, idx, max_new_tokens):
    for _ in range(max_new_tokens):
        # Context 길이를 모델의 한계치로 자름
        idx_cond = idx[:, -self.config.block_size:]
        
        # 모델에 입력하여 Logits 획득 (Loss는 무시)
        logits, _ = self(idx_cond)
        
        # 마지막 토큰(시계열의 맨 끝)의 Logits만 추출
        logits = logits[:, -1, :] 
        
        # Softmax로 확률 분포 변환
        probs = F.softmax(logits, dim=-1)
        
        # 확률에 따라 다음 토큰 1개 샘플링 (주사위 굴리기)
        idx_next = torch.multinomial(probs, num_samples=1)
        
        # 기존 시퀀스에 생성된 토큰 이어붙이기 (Append)
        idx = torch.cat((idx, idx_next), dim=1)
        
    return idx

자기회귀적(Autoregressive) 생성

LLM이 텍스트를 만들어내는 과정을 코드로 명확히 볼 수 있습니다.

  • logits[:, -1, :]: 방금까지 입력된 문맥을 보고 예측한 '바로 다음 단어'의 점수만 가져옵니다.
  • torch.multinomial: 가장 높은 점수를 무조건 고르지 않고 확률 분포에 따라 샘플링합니다. (다양한 문장 생성의 이유)
  • torch.cat: 예측된 단어를 입력의 맨 뒤에 붙이고, 다시 루프의 처음으로 돌아갑니다.

정리: microGPT가 알려주는 진실

단순한 구조의 반복

수십억 개의 파라미터를 가진 거대한 GPT-4나 챗GPT도 근본적인 뼈대는 이 Block (Attention + MLP)의 거대한 반복에 불과합니다.

마법이 아닌 확률 연산

AI가 문맥을 '이해'하는 것처럼 보이지만, 내부적으로는 단순히 벡터의 내적(Q * K^T)과 확률 샘플링(multinomial) 연산입니다.
